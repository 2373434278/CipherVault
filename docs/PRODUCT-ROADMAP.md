# 产品路线图

本文记录密匣的功能扩展候选、优先级与 v1.1 PRD。产品定位是**本地优先**：不联网、不上传、不依赖云服务。

## 约束

- 不新增 INTERNET 权限，不接入在线泄露查询（HIBP 等）。
- 体检、评分等结果只在内存中计算，不持久化、不打印。
- 数据库变更必须配套显式迁移，禁止 destructive migration。

## 候选功能与 ICE 评分

ICE = Impact（影响）× Confidence（信心）× Ease（实现容易度），各项 1–10。

| 优先级 | 方向 | 候选功能 | ICE | 结论 |
| --- | --- | --- | --- | --- |
| 1 | 安全 | 离线密码安全体检（弱密码 / 重复 / 缺 TOTP） | 8.7 | **v1.1 已落地** |
| 2 | 效率 | 长按快捷操作、置顶、排序模式 | 8.0 | **v1.2 已落地** |
| 3 | 体验 | 主题 / 字号 / 无障碍 | 7.3 | v1.2 |
| 4 | 效率 | 标签 / 带标签自定义字段（优先复用 payloadJson，无迁移） | 7.0 | v1.2 |
| 5 | 效率 | 多选批量移动 / 删除 | 6.7 | v1.3 |
| 6 | 安全 | 密码修改时间 + 过期提醒（需 v1→v2 迁移） | 5.7 | v1.2 / v1.3 |
| 7 | 安全 | 可打印恢复套件（离线文件） | 6.3 | v1.3 |
| — | 安全 | 泄露监测（HIBP 等） | — | 暂缓：需联网，违背 local-first |

## 路线图

- **v1.1（当前）**：密码安全体检。
- **v1.2（进行中）**：长按快捷操作、置顶与 4 种排序已落地；标签 / 自定义字段（payloadJson，无迁移）与密码过期提醒（需 v1→v2 迁移）待后续。
- **v1.3**：主题 / 字号 / 无障碍、批量操作、离线恢复套件。
- 泄露监测仅在用户明确接受联网后作为可选功能，单独评估权限与隐私声明。

## v1.1 PRD：密码安全体检

### 问题

用户无法判断保险库内密码是否健康。现有「设备安全评分」只反映生物识别、截屏保护等设备开关，不反映条目质量。

### 目标

一次进入即可看到待修复项，并能直接跳转到对应条目修改。

### 非目标

- 联网泄露查询。
- 自动改密或密码轮换。
- 持久化体检历史或趋势。

### 规则

- 审计范围：未删除、类型为「登录」且密码非空的条目。
- 弱密码：`PasswordGenerator.strength(password) <= 1`。
- 重复使用：密码完全一致（区分大小写）且至少出现在 2 个条目中。
- 缺少 TOTP：条目有网址且未配置 TOTP。
- 已移入回收站的条目不计入。

### 交互

设置 →「密码安全体检」→ 评分卡（评分、已检查数量、待处理数量）+ 弱密码 / 重复使用 / 缺少双重验证三个分区 → 点击条目进入详情。

### 隐私

- 仅在 `Dispatchers.Default` 内存中计算。
- 结果不保存、不打印、不上传。
- 重复检测仅在内存中对密码做 SHA-256 分组，指纹不进入结果对象。

### 验收标准

- 3 条相同密码显示为 1 组 3 项重复。
- 全部强、唯一且带 TOTP 的登录显示健康空态。
- 条目移入回收站后，对应问题计数下降。
- 中英文切换后文案完整。
- 锁定、解锁或重新进入页面后结果自动重算。

### 指标

无遥测。以用户复访时「待处理」数量下降作为代理指标。

## v1.2 PRD：长按快捷操作与排序

### 目标

减少进入详情页的操作步骤，并让用户按自己的习惯浏览列表。

### 规则

- 长按条目打开快捷面板，仅展示当前条目可用的操作：
  - 复制用户名（用户名非空）
  - 复制密码（密码非空）
  - 复制验证码（已配置 TOTP）
  - 置顶 / 取消置顶
  - 收藏 / 取消收藏
  - 编辑
  - 移入回收站（二次确认）
- 排序模式：置顶优先（默认）、最近更新、最近创建、名称 A-Z。
- 排序偏好持久化到 DataStore，重启后保留。
- 列表平铺展示，不再自动插入收藏分组；收藏仍作为筛选标签与星标保留。
- 置顶为独立字段，不影响收藏状态；置顶项始终排在列表最前。
- 筛选条件保持不变，排序在筛选结果内生效。

### 隐私

- 复制沿用现有剪贴板自动清除与 Android 13+ 敏感内容标记。
- 快捷面板不记录、不上传任何条目数据。

### 验收标准

- 长按条目弹出面板，点击操作后面板关闭且行为正确。
- 无用户名、无密码、无 TOTP 时不显示对应复制项。
- 4 种排序结果符合预期，重启应用后仍保持所选排序。
- 置顶项在默认排序下位于最前，取消置顶后回到时间序。
- 编辑置顶条目不会丢失置顶状态。
- 删除操作必须二次确认，确认后条目进入回收站。

### 数据迁移

- Room v1 → v2 增加 `pinned` 字段：
  `ALTER TABLE vault_items ADD COLUMN pinned INTEGER NOT NULL DEFAULT 0`。
- 旧安装升级后所有条目默认未置顶；新建数据库直接包含该字段。
- 自有加密备份与 CSV 导出/导入保留 `pinned`；旧备份缺少该字段时按未置顶处理。
